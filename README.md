承載希望，智慧同行 —— 承智教育 CHANGE Education

## 核心價值 Core Values 
- C - Compassion (關懷誠心)： 誠摯對待每位學生與家長，以溫暖與同理心作為教育的基石。
- H - Holistic (全人視野)： 注重知識、品格與思考習慣的全方位養成。
- A - Achievement (成就卓越)： 對教學品質精益求精，陪伴學生設定目標並逐步實現。
- N - Nurture (深耕培育)： 像灌溉幼苗般耐心陪伴，信任並等待學生的成長與蛻變。
- G - Growth mindset (成長心態)： 鼓勵學生與教職員勇敢面對挑戰，視挫折為進步的契機。
- E - Empowerment (賦能未來)： 給予學生自主學習的能力與工具，真正改變自己的未來。

## 教育理念  
- 因材施教： 掌握學生學習節奏，精準補強弱項。
- 雙軌輔導： 解惑課業疑難，同步引導學習心態。
- 家長同行： 定期學習反饋，建立最緊密的親師合作關係。
